# Vídeos – busca acessível no YouTube

App web para buscar e assistir vídeos do YouTube em iPad com iOS 12, seguindo a WCAG 2.2 nos níveis A e AA.

- Funciona no Safari do iOS 12 (sem recursos modernos de JavaScript/CSS).
- Controles próprios e acessíveis: Reproduzir/Pausar, Voltar e Avançar 10 segundos, Legendas e Fechar.
- Avisos para leitor de tela, foco gerenciado e texto que acompanha o tamanho de fonte do sistema.
- A chave da API do YouTube é digitada no próprio aparelho e fica só nele; não está no código.

## Uso
1. Abra o site no Safari do iPad e toque em Compartilhar > Adicionar à Tela de Início.
2. Abra pelo ícone e cole a chave da YouTube Data API v3 em Configurações.
